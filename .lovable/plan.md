# מעבר לסוכן AI עם מפתח Anthropic שלך

הסוכן שמשמש את המשתמשים באתר (חיפוש נכסים חופשי בעברית) פועל כיום דרך שער ה‑AI המנוהל של Lovable ומחויב לקרדיטים של הפרויקט. המעבר יעביר אותו לחיוב ישיר מול חשבון Anthropic שלך.

## מה יקרה

1. תתבקש להזין מפתח Anthropic (`ANTHROPIC_API_KEY`) בטופס מאובטח — המפתח נשמר מוצפן וזמין רק לקוד בצד שרת, לא לדפדפן.
2. סוכן החיפוש יקרא ל‑Anthropic Messages API במקום לשער של Lovable, עם אותו System Prompt, אותם כללי "אסור להמציא נתונים" ואותו מבנה JSON של פילטרים.
3. שכבת האימות והניקוי הקיימת (`sanitize`) נשארת בלי שינוי, כך שגם אם המודל מחזיר משהו לא צפוי — הפילטרים נשארים בטוחים ורק שכונות אמיתיות עוברות.
4. הודעות שגיאה בעברית נשמרות: חריגת מגבלת בקשות, מפתח חסר/לא תקין, וכשל כללי → נפילה חזרה לסינון הרגיל.
5. המשתמשים באתר לא צריכים מפתח, לא נדרש חשבון, ולא משתנה שום דבר בחוויה שלהם.

## פרטים טכניים

- קובץ יחיד שמשתנה: `src/lib/ai-search.server.ts`.
  - קריאה ל‑`https://api.anthropic.com/v1/messages` עם הכותרות `x-api-key` ו‑`anthropic-version: 2023-06-01`.
  - מודל: `claude-sonnet-4-5` (איזון עלות/דיוק), `max_tokens` נמוך, `system` = ה‑Prompt הקיים + רשימת השכונות המותרות.
  - קריאת `process.env["ANTHROPIC_API_KEY"]` בתוך ה‑handler בלבד.
  - חילוץ הטקסט מ‑`content[0].text`, ניקוי גדרות ```json אם יופיעו, ואז `JSON.parse` בתוך try/catch כמו היום.
- ללא שינוי: `ai-search.functions.ts`, ה‑UI של החיפוש, וכל מסלולי ה‑CMS.
- `LOVABLE_API_KEY` נשאר בפרויקט אך לא ייקרא יותר בקוד החיפוש.

## הערה על עלות

החיוב יעבור לחשבון Anthropic שלך לפי שימוש. אין הגבלת קצב מובנית לכל משתמש — אם תרצה, אפשר להוסיף בשלב נפרד הגבלת בקשות פר משתמש/IP כדי למנוע צריכה חריגה.
