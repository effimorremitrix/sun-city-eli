# תוכנית: שם משתמש, התנתקות וקישורים עליונים

## מטרה
כשמשתמש מחובר לאתר, יופיע שמו בכותרת העמוד, יוצע כפתור התנתקות, וקישורי "האזור האישי שלי" ו"ניהול האתר" יחזרו לראש העמוד (הדר). השינויים יחולו גם בהדר וגם באזור האישי.

## מה ייבנה

1. **שדה שם מלא למשתמשים**
   - הוספת עמודה `full_name` לטבלת `profiles`.
   - עדכון טריגר ההרשמה כדי לשמור את השם ממטא-דטה של auth.users.
   - הוספת שדה "שם מלא" בטופס הרשמה ב-/auth.

2. **הצגת שם והתנתקות בהדר**
   - יצירת hook `useAuth` שמחזיר את המשתמש המחובר, שם תצוגה, סטטוס admin ופונקציית logout.
   - עדכון `Header.tsx`: כשיש משתמש — יופיע "שלום, {שם}" + קישור לאזור האישי + קישור לניהול (ל-admin) + כפתור התנתקות. בתפריט המובייל יופיעו אותם פריטים.

3. **שדרוג אזור אישי**
   - עדכון `getMyAccount` כדי להחזיר גם את `full_name`.
   - הצגת השם בכותרת העמוד ואפשרות לערוך אותו.
   - שימוש באותה פונקציית logout מסודרת גם בעמוד /account.

4. **העברת קישורי הניהול לראש העמוד**
   - הקישורים "האזור האישי שלי" ו"ניהול האתר" יתווספו להדר העליון עבור משתמשים מחוברים (admin יראה גם "ניהול").
   - הקישורים יישארו זמינים גם בפוטר כמו היום.

## פרטים טכניים

- **מסד נתונים**: מיגרציה חדשה שמוסיפה `full_name text` ל-`public.profiles`, מעדכנת את `handle_new_user`, ומעניקה הרשאות SELECT/UPDATE מתאימות.
- **שרת**: עדכון `getMyAccount` ב-`src/lib/account.functions.ts` לשלוף את `full_name` מטבלת `profiles` ולהחזיר אותו יחד עם `isAdmin` והתראות.
- **לקוח**: ה-hook `useAuth` ישתמש ב-`supabase.auth.getUser()` ו-`onAuthStateChange`, וישאב את `full_name` מ-`profiles` דרך שאילתה פשוטה. ה-logout תבצע: ביטול שאילתות פעילות, ניקוי מטמון, `supabase.auth.signOut()` וניווט ל-/auth עם `replace: true`.
- **SSR**: ההדר נטען בשרת, לכן מצב המשתמש יטען בצד הלקוח בלבד (useEffect) כדי למנוע אי-התאמת hydration.
- **UI**: השם והכפתורים יופיעו בצד ימין של ההדר (ב-RTL זה הצד המתאים למשתמש מחובר), עם אייקון LogOut מ-lucide-react.
